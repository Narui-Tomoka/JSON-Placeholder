## 制作の流れ

### コンセプト・デザイン作成

1. 実装内容を確認し、どのようなサイトにするかアイデアを出す
2. カラーコードを決める
3. Relume Library（Figma 拡張機能）用のプロンプト作成  
   chatGPTを使用して英語で出力
4. Relume Library でワイヤーフレーム作成
5. ワイヤーフレームの内容を精査・調整  
   日本語の違和感、ボタンの文言を調整
6. カラーコードをFigmaに入れておく  
   同じページ内のカラーとして呼び出しやすくなる  
   視覚的に理解しやすくなる
7. 実装に必要な入力フォームのデザイン作成  
   ボタンや入力フォームの部品はコンポーネントにしておく  
   入力フォームはplaceholderのテキストを作成して「Shift + A」でオートレイアウトにする  
   （四角形を作ってテキストを入れるわけではない）
8. デザインした入力フォームをワイヤーフレームに組み込む  
   要素を左パネルで選択して↑↓キーで簡単に順序を変えられる
9. ワイヤーフレームに色を付ける  
   生成したワイヤーフレームには白黒なので色を付けておく
10. ロゴを作成  
    2026年2月現在 GeminiよりchatGPTの方が上手
11. ロゴの文字抜けを修正し、ワイヤーフレームに挿入  
    Figmaでマスク機能やfill、グラデーションカラーを使って違和感なく調整
12. Hero画像に使う写真風の画像をAdobe Fireflyで生成  
    プロンプトはchatGPTを使用し英語で作成
13. 架空の人物名や設定を作成  
    chatGPTで画像生成  
    2026年2月現在 GeminiよりchatGPTの方が絵が上手  
    架空の人物名は Geminiの方が好みに合った
14. 作成したワイヤーフレームを画像ファイルとして出力  
    （画像データを渡してコーディング補助に利用するため）

## 前回の課題「WDC」の反省点

### clamp()の使い過ぎ

clamp()の使用によりブレイクポイントの記述を減らすことはできたが、余白やフォントサイズが中途半端になってしまった。  
後に調べたところ、8の倍数でそろえたほうが画面が引き締まった印象になることがわかったので、**clamp()は便利だが使いどころを考える必要がある**と感じた。

## 今回の課題で心がけたこと

### 余白やフォントサイズをできるだけ8の倍数でそろえる

1. 「8の倍数ルール」で余白とサイズを統一する  
   「8px（8の倍数）」をベースにしたグリッドシステムが標準的。

- なぜ8なのか？  
  多くの画面解像度は8で割り切れ、拡大縮小してもズレにくい（小数点が出にくい）ためです。
- どう使う？  
  padding（内側の余白）、margin（外側の余白）、画像の高さや幅などを、すべて 8, 16, 24, 32, 48... といった数字で統一します。
- 微調整  
  8pxでは広すぎると感じる細かい部分は、4px（ハーフステップ）を使ってもOKです。

2. 文字サイズと行間の黄金比  
   文字は単に大きくするのではなく、「階層（ヒエラルキー）」を意識すると美しくなります。

- 文字サイズ  
  本文を「16px」とし、見出しなどは「24px（1.5倍）」「32px（2倍）」「48px（3倍）」のように比率で決めるとバランスが整います。
- 行間（line-height）  
  本文の読みやすさを決める最重要ポイントです。フォントサイズの 1.5倍〜1.8倍 に設定するのがWebの王道です。  
  例：font-size: 16px; なら line-height: 1.6;（実質 25.6px）程度。
- 行間も8の倍数に？  
  さらにこだわりたいなら、行間（line-heightの計算値）を8の倍数に合わせると、ページ全体の「縦のリズム」が完璧に揃います。

3. 「近接の原則」で情報を整理する

- 関連するものは近く、違うものは遠く  
  例えば、タイトルと本文の間の余白は狭くし、次のセクションとの間の余白は広く（1.5倍〜2倍以上）取ります。
- 余白を恐れない  
  初心者は隙間を埋めたくなりますが、プロは「余白（ホワイトスペース）」を「何もない空間」ではなく **「情報を際立たせるための要素」** として贅沢に使います。

4. フォントの数を絞る  
   多くのフォントを使うと雑多な印象になります。
   最大2〜3種類まで  
   基本は「本文用」と「見出し用」の2種類、あるいは1つのフォントファミリーで太さ（Weight）を使い分ける。

## 備忘録

### 文字サイズのそろえ方

フォントサイズは必ずしも「8の倍数」である必要はありません。むしろ、文字の大きさについては「タイポグラフィック・スケール」という比率に基づいた考え方が一般的です。

1. 本文（Base）のサイズを決める  
   まずは、サイトの土台となる本文のサイズを決めます。

- 基本は16px  
  多くのブラウザのデフォルト設定であり、GoogleやAppleも推奨する「読みやすさ」の基準です。
- 例外： 記事主体のメディアなら少し大きめの18px、ツール系の緻密な画面なら14pxにするなど、サイトの目的に合わせて調整します。

2. 「倍率（スケール）」でサイズ展開を作る  
   見出し（H1, H2...）のサイズを「なんとなく」で決めると、画面がバラバラな印象になります。  
   そこで、一定の「比率」を掛け合わせてサイズを決めていきます。
   これを「モジュラースケール」と呼びます。

- 1.2倍 (Minor Third)  
  自然で落ち着いたバランス。一般的。 16px → 19.2 → 23.0...
- 1.25倍 (Major Third)  
  メリハリがはっきりし、見出しが際立つ。 16px → 20 → 25 → 31.3...
- 1.5倍 (Perfect Fifth)  
  非常にインパクトが強く、大胆なデザイン。 16px → 24 → 36 → 54...
- プロの工夫  
  計算で出た「19.2px」のような端数は、コーディング時に Figma 等のデザインデータ上で 20px や 18px に丸める ことが多いです。  
  ここで「8の倍数」や「4の倍数」に丸めると、全体の一貫性がさらに高まります。

3. 実装は「rem」を使いこなす  
   HTML/CSSで実装する際は、px で固定せず、rem（ルート要素に対する倍率）を使うのが今のWeb制作のスタンダードです。

- 例： font-size: 1.25rem;（16pxが基準なら20px相当）
- メリット  
  ブラウザの設定で文字サイズを変えてもレイアウトが崩れず、アクセシビリティ（誰にでも使いやすい設計）に配慮した「プロのコード」になります。
